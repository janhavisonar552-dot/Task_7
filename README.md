# Laundry Services - Task 7

## Task
CSS Responsive Issue - Media Queries and Variables

## Description
This project is a responsive laundry services webpage created using HTML and CSS.

The webpage is designed to work properly on:

- Desktop
- Tablet
- Mobile

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- CSS Variables

## Features

- Responsive navigation bar
- Responsive hero section
- Responsive text sizes
- Responsive image
- Mobile navigation links are hidden
- Flexbox used for layout
- CSS variables used for colors
- No Bootstrap used

## Responsive Design

### Desktop
The text and laundry image are displayed side by side.

### Tablet
Font sizes and image sizes are reduced to fit the tablet screen.

### Mobile
Navigation links are hidden and the hero section changes to a column layout.

## Files

- index.html
- style.css
- laundry.png
- README.md

## How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Open index.html.
4. Run using Live Server.
